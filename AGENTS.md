# Physora Workspace Guidelines

## Critical Storage & Drive Rule
- **Main Drive is D: (D:\Physora)**: The entire repository, source code, builds, dependencies, artifacts, and test scripts reside exclusively on D:\Physora.
- **Zero additions to C: Drive**: Never create or place files, builds, temporary assets, or node_modules on the C: drive.
- All command executions and file operations target D:\Physora.
